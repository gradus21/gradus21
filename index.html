Gradus21 APT Repository

Automatische Updates für Debian, Ubuntu, Pop!_OS und Linux Mint (Version 1.2.11)

1 GPG-Schlüssel importieren

Importiere den kryptografischen Release-Schlüssel von Gradus21 in deinen System-Keyring:

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://gradus21.github.io/gradus21/KEY.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/gradus21.gpg
sudo chmod a+r /etc/apt/keyrings/gradus21.gpg

2 Paketquelle hinzufügen

Trage das offizielle Gradus21 Repository in deine APT-Quellen ein:

echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/gradus21.gpg] https://gradus21.github.io/gradus21 stable main"   | sudo tee /etc/apt/sources.list.d/gradus21.list

3 Installieren & Aktualisieren

Aktualisiere die Paketlisten und installiere Gradus21:

sudo apt update
sudo apt install gradus21
Von nun an wird Gradus21 bei jedem regulären sudo apt update && sudo apt upgrade automatisch mitaktualisiert.
